📥 التثبيت — Linux (apt)

سطر واحد يضيف المستودع، ثم ثبّت الحزمة كأنها أي برنامج عادي:

curl -fsSL https://ragaeidos.website/justgivenup/install.sh | sudo sh
sudo apt update && sudo apt install justgivenup
تنزيل install.sh إكستنشن Chrome (zip) إكستنشن Firefox (.xpi)

بعد التثبيت افتح http://127.0.0.1:8081 وأكمل المعالج. الخدمة تعمل تلقائيًا مع إقلاع النظام.

التثبيت يدويًا بدون سكربت 
echo "deb [trusted=yes] https://ragaeidos.website/justgivenup stable main" \
  | sudo tee /etc/apt/sources.list.d/justgivenup.list
sudo apt update && sudo apt install justgivenup

يعمل على Debian وUbuntu وMint والأنظمة المشتقة. الـ signed-release متاح عند توقيع المستودع.

🛡️ كيف يعمل؟

  • 🔒 قفل زمني لا يمكن إيقافه — المدة تحدّدها أنت (1–3650 يوم). بمجرد بدئه لا يستطيع أحد — لا أنت ولا الإكستنشن ولا السطر — إزالته أو تقصيره. العبث بالملفات يضيف 90 يومًا.
  • 🧩 إكستنشن Chrome وFirefox — يحجب مباشرةً فوق 12,000 موقع إباحي بـ declarativeNetRequest، مع واجهة تحفيزية عند المحاولة.
  • 🌐 سياسات متصفحات إجبارية — URLBlocklist يُثبَّت عبر postinst ولا يمكن تعطيله من واجهة المتصفح.
  • 📛 حجب DNS على مستوى النظام — /etc/hosts يحجب أكثر من 150,000 نطاق أثناء القفل حتى لو حُذف الإكستنشن.
  • ⏰ يعمل دائمًا — خدمة systemd + حارس كل 30 ثانية يعيد التشغيل لو أوُقفت، ويبدأ تلقائيًا مع الإقلاع.
  • 📊 لوحة تعافي — أيام نظيفة، انتكاسات، رتب، سجل، كلمات تحفيزية (عربي/إنجليزي).
